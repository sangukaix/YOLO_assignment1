FaceAge 수행과제2 소스 코드

얼굴나이예측/train.py: 최종 EfficientNetV2-S 학습 코드
얼굴나이예측/experiments/: 모델, 데이터 양, 미세조정 범위 비교 코드
얼굴나이예측/prepare_data.py: 데이터 통합 및 중복 제거
얼굴나이예측/evaluate.py: 성능 지표 계산
얼굴나이예측/face_landmarks.py: 얼굴 특징점 및 유사도 계산
얼굴나이예측_발표웹/: 웹 화면과 나이 예측, 강아지 검색 코드
얼굴나이예측/results/: 저장된 학습 로그, 지표 및 최종 검증 예측값

이 ZIP은 소스 코드 제출용입니다. 데이터셋, 학습된 모델 가중치, 가상환경, 실행 중 생성된 임시 파일은 제외했습니다. 다른 PC에서 학습 및 웹 분석을 실행하려면 해당 자료를 별도로 준비하고 코드의 로컬 경로를 맞춰야 합니다. 실행 환경은 각 폴더의 requirements 파일에 기록되어 있습니다.

공개 강아지 특징점 모델 출처와 라이선스는 얼굴나이예측/models/face_landmarks/에 포함되어 있으며, prepare_models.py로 공개 모델 파일을 준비할 수 있습니다. 나이 예측 모델의 가중치는 별도로 필요합니다.
