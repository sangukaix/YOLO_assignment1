# 얼굴 나이 예측 및 닮은 강아지 검색

CNN 전이학습 수행과제 소스 코드입니다. 얼굴 사진으로 나이를 예측하고, 얼굴 비율을 비교하여 닮은 강아지를 찾습니다.

- `얼굴나이예측/train.py`: EfficientNetV2-S 학습
- `얼굴나이예측/experiments/`: 모델·데이터 양·미세조정 범위 비교
- `얼굴나이예측/prepare_data.py`: 나이 라벨 통합 및 중복 제거
- `얼굴나이예측/evaluate.py`: 성능 평가
- `얼굴나이예측/face_landmarks.py`: 얼굴 특징점 및 비율 계산
- `얼굴나이예측_발표웹/`: Streamlit 웹 화면과 예측·검색
- `얼굴나이예측/results/`: 학습 기록, 평가 지표, 최종 검증 예측값

훈련 10,190장, 검증 2,546장을 사용했습니다. 최종 모델은 10회 학습 중 검증 MAE가 가장 낮았던 9회차이며, 검증 MAE는 4.99세입니다.

## 실행에 필요한 자료

소스 코드 제출용 저장소로, 데이터셋·가상환경·모델 가중치는 포함하지 않았습니다. 전체 서비스를 실행하려면 나이 학습 데이터, 나이 모델 가중치, 강아지 검색 목록과 원본 사진을 별도로 준비하고 코드의 로컬 경로를 맞춰야 합니다. 의존성은 각 폴더의 requirements 파일에 기록되어 있습니다. 기존 실행 스크립트는 원래 PC의 `전이학습/.venv` 환경을 사용합니다.

공개 특징점 모델은 `얼굴나이예측/prepare_models.py`로 준비할 수 있습니다. 강아지 모델의 출처·라이선스는 `얼굴나이예측/models/face_landmarks/`에 포함했습니다. 해당 공개 모델은 추가 학습 없이 특징점 추출에 사용했습니다.
